## 🐛 Bestiary

You were warned: the bugs are everywhere. Know your enemy.

| Creature | Habitat | Weakness |
|---|---|---|
| 👺 Off-by-One Goblin | Loops, pagination | Boundary tests |
| 👻 Race Condition Wraith | Async code, job queues | Locks, idempotency |
| 🐍 N+1 Hydra | ORMs | Eager loading, one good JOIN |
| 🧟 Null Zombie | Every API response | Strict types, null-safety |
| 🐉 Works-On-My-Machine Dragon | Prod | Docker, CI, humility |
